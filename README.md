# กล่องเครื่องมือ PDF

เว็บจัดการไฟล์ PDF ที่ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

รวม แยก ลบหน้า จัดเรียงหน้า สแกน บีบอัด ซ่อมแซม แปลง Word / Excel / PowerPoint / HTML / JPG เป็น PDF และกลับกัน
แก้ไข PDF (ข้อความ ไฮไลท์ ปากกา รูปร่าง ลายเซ็น) หมุน เลขหน้า ลายน้ำ ครอบตัด กรอกฟอร์ม ปลดล็อก ใส่รหัส ถมดำ เปรียบเทียบ

เปิดใช้งาน: https://rachanon98743-lang.github.io/pdf-tools/

ไลบรารีที่ใช้: pdf-lib, PDF.js, JSZip, SheetJS, mammoth, html2canvas, PptxGenJS, qpdf (WebAssembly)
